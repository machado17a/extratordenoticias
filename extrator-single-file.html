ℹ️ Como usar:

  2. Clique em "Extrair Notícia"

  4. Clique em "Copiar para WhatsApp" para copiar o texto formatado
  5. Cole no WhatsApp (o texto manterá a formatação)
Nota: Este extrator funciona melhor com sites de notícias que seguem padrões HTML semânticos. Devido a restrições de segurança (CORS), a maioria dos sites bloqueia extração direta via navegador. Para produção, recomenda-se implementar um backend.
